# Navigation Search v9.9

v9.9 builds a portable search index from declarative menu files and the command registry.

## Features

- Search menu labels, descriptions, categories and handlers.
- Jump directly to canonical submenus or execute registered actions.
- Rank tools by local usage count.
- Rebuild and audit the index without external databases.
- POSIX shell implementation compatible with iSH-AOK filesystems.

State is stored under `~/.local/state/ish-aok-config/navigation-v990/`.
