# iSH-AOK Config v11.0.1

## RootFS Builder Framework

- Added a RootFS-first dashboard with profiles, package sets, queue, repositories, keyrings, cache, validation, artifacts, and management routes.
- Added Minimal, Standard, Developer, Server, Container Host, and Recovery build profiles.
- Added distribution-aware package-set resolution with recursive includes and deduplication.
- Added isolated builder cache namespaces.
- Added pre-build validation, post-build validation, reproducibility manifests, and queue job snapshots.
- Preserved existing v10.12 build backends, keyring cache, RootFS management, and advanced tools.
